## 项目简介

在信息过载的时代，我们致力于为您提供一方纯净、安全的记账空间。Piggy Bank 摒弃了繁琐的云端同步与广告干扰，回归财务管理的本质：记录与规划。所有数据均严格存储于您的设备本地，确保每一笔资金变动都分毫不差且绝对隐私。

## 核心特性

- **安全与隐私**：采用纯本地文件存储机制与处理，无需联网权限，杜绝数据泄露风险。您的财务数据完全掌握在您自己手中。
- **多目标与进度管理**：支持“累积型”与“目标型”双模式存钱罐，直观展示存款进度与达成百分比。
- **自定义手势交互**：支持卡片滑动快捷存取，并允许在设置中高度自定义左滑/右滑触发的快捷指令。
- **国际化支持**：内置中英双语无缝切换机制，并提供首次启动语言引导流程。
- **账单**：提供按日期折叠的流水视图，并针对移动端优化布局，让收支状况一目了然。
